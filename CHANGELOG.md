- Added `docs/AUTONOMOUS_WORKFLOW.md` and a corresponding ADR (2026-08-02): the operative workflow for Phase 4's tail through Phase 6 — one persistent "Senior Dev" session, PR review dispatched to a fresh independent Claude Code session (alongside Copilot, not replacing it), ambiguity handling that blocks only dependent tasks, explicit "large problem" escalation triggers, and a Phase 5 pre-flight checklist (Netlify/VPS account setup, secrets, budget) since infrastructure carries a different risk class than pure code. - Phase 4 E2E suite (2026-08-07, issue #37): Playwright covering four critical journeys — browse/filter/detail, contact submit, contact rate-limit, and admin login→publish→logout→guard — in a new top-level `/e2e` package rather than inside `frontend/`, so Netlify's Phase 5 build never installs a browser-automation framework. Seeds and cleans up through the real HTTP API; the one direct database write (provisioning a test-only `e2e-admin`, unavoidable since there's no registration endpoint and the seeded admin's password was never committed) is guarded against running on any non-localhost host. Verified 7/7 twice back-to-back with no database wipe between, proving rerunnability. See `docs/DECISIONS.md` for the ADR

- Phase 6 performance pass (2026-08-07, issue #51, PR #83): build budgets replaced with values that can actually fire (the stock `initial` budget was 500 kB warn against 284 kB of real output), a request waterfall removed from the landing route, layout shift eliminated by reserving the detail gallery's box, and LCP hints added to the first rendered image. `NgOptimizedImage` was evaluated against `@angular/common` source and deliberately **not** adopted — automatic `srcset` needs a CDN loader that cannot exist for arbitrary admin-pasted origins, preload injection is SSR-only, and the oversized-image assertion never runs without known intrinsic dimensions. Two findings surfaced during review: the LCP hint silently no-op'd when the newest project had no images, and `path: ''` without `pathMatch` prefix-matched every URL. Also documented a silent-failure trap worth remembering — an Angular `bundle` budget naming a chunk that does not exist is ignored entirely, no warning, exit 0

- Agent-termination handling documented (2026-08-08, PR #84): a dispatched agent that dies on an API/session limit should be **resumed** via `SendMessage` with its agent ID, which the tooling states preserves its context — not salvaged by hand. Three agents were lost this way on 2026-08-07 and all three were salvaged manually; one had died mid-mutation-test and left a deliberate defect in the working tree beneath a comment saying the opposite, which nearly shipped. New "When a dispatched agent dies mid-task" section in `CLAUDE.md`, cross-referenced from `docs/AGENT_WORKFLOW.md` (with the worktree-lifecycle consequence: a dead agent's worktree isn't free while a resume is still possible) and `docs/AUTONOMOUS_WORKFLOW.md`
- GitHub Copilot suspended from the merge gate until 2026-08-25 (2026-08-08) while its quota is exhausted — it answers review requests with a quota error rather than a review. Recorded as a dated, deliberate deviation in `docs/AUTONOMOUS_WORKFLOW.md`, `docs/DECISIONS.md` and `PROJECT_TODO.md`, since a quota error is not the same claim as "the reviewer found nothing". The independent-session review is mandatory and has no fallback; the merge gate was also reworded to fail closed after a first draft ("every *available* review layer") would have passed when no layer ran at all

- Project date period (2026-08-08, issue #85): `startedOn` plus a nullable `completedOn` on `Project`, closing a spec/model divergence that had been open since Phase 0 — `SPEC.md` promised "dates" on project detail while the data model only ever had `created_at`/`updated_at`, which are record timestamps, not dates describing the work. Null `completedOn` means **ongoing**, a value rather than missing data. Built contract-first: `docs/openapi.yaml`, `docs/DATA_MODEL.md` and the ADR landed and validated before any code, then backend then frontend against the same settled contract, neither reading the other. Stored at day precision, **rendered month/year only** — the source material can't support a day and showing one would assert something unknowable. Enforced twice: cross-field DTO validation for a clean RFC 7807 400, plus a table `CHECK` written so it can never evaluate to NULL (a naive `completed_on >= started_on` would have silently permitted a completed-but-never-started row, since a `CHECK` passes on NULL)

- Backend correctness checklist added to `CLAUDE.md` (2026-08-09, PR #94): seven standing risks, each traced to a real bug that `mvn test` alone did not catch across Phases 1-2, framed as recurring hazards rather than history. Two claims in the source draft were corrected before committing — the phase attribution, and a "never log a credential even at DEBUG" rule that would have contradicted a deliberate decision in `ResendEmailClient`. Review then found the *same* contradiction one bullet later, in the config-validation item, and three invented mechanisms in the accompanying `docs/AGENT_WORKFLOW.md` worktree guidance; all corrected, and logged in `AGENT_LOG.md` as a recurring authorial habit of fabricating the *because* behind a real observation
- `docs/AGENT_WORKFLOW.md` worktree-cleanup guidance now distinguishes a husk nested inside the repo (silently reports the main checkout's state) from a sibling one (`fatal: not a git repository`), names parent-directory discovery as the actual mechanism rather than a dangling gitfile, and explains what a large foreign-work-tree diff actually means instead of dismissing it

- Stale-reference safeguard in `CLAUDE.md` (2026-08-09, PR #95): a path alone is not a reference, since this repo is worked through many simultaneous checkouts and none is reliably `main`. Provenance is a **commit plus a dirty flag** (`git rev-parse --short HEAD` and `git status --porcelain`), not a branch name — `git rev-parse --abbrev-ref HEAD` returns the literal string `HEAD` in the detached worktrees this project mandates for PR review, and a branch name says nothing about uncommitted edits on top. Machine-specific counts and layout moved to `docs/AGENT_WORKFLOW.md` as an explicitly perishable snapshot, so `CLAUDE.md` carries only what stays true
- Recorded that `git cherry` and patch-ids answer "is this *commit* present", not "is this *content* present" (2026-08-09) — two commits on `phase3/frontend-foundation` appeared stranded until the added lines were compared and found byte-identical to commits already in `main`

- Content rendering prepared for real portfolio copy (2026-08-09, issues #86 and #87, PR pending): project cards now show a bounded excerpt of the first paragraph instead of the entire description, and gallery images are no longer announced as "screenshots". Both were blocking #49 — the drafted entries run 1,000–2,400 characters each and Equalizer's images are architecture diagrams. The clamp is deliberately **two** limits: a TypeScript excerpt bounding what reaches the DOM, because `overflow: hidden` hides text visually while leaving it fully in the accessibility tree, plus a CSS `line-clamp` for uniform card heights that survives zoom and larger font sizes. Measured in a real browser: page height 2098 → 1050 px at 375 px wide, description boxes exactly 3 lines at both mobile and desktop widths and at a 32 px body font
- Image alt text now asserts only what the frontend can actually know — `"<title>, image 1 of 2"` for gallery images, and `alt=""` for the card thumbnail, which sits inside a link whose visible text is already the title and was making the link announce the title twice. Same WAI rule, opposite answers, applied per-image rather than by convention. This is the honest ceiling without per-image alt text in the data model; see the follow-up issue
